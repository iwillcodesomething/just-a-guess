The source data is provided as is, without warranty of completeness or accuracy.
`geography.json` groups this data by country and omits historical CS/AN codes.
Place coordinates and current location metadata are resolved through Open-Meteo
Geocoding when the user selects a place. This bundled directory is not live data.
